# Design influences

YallaFlow is an independent implementation shaped by lessons from the broader AI-assisted software-development ecosystem.

## Squad-Kit
Useful design lessons include lean execution contracts, separating planning from execution, bounded repository discovery, tracker ingestion, health checks, and package-owned prompts/workflows.

[Squad-Kit](https://github.com/AzmSquad/Squad-Kit) is available under the [MIT License](https://github.com/AzmSquad/Squad-Kit/blob/main/LICENSE).

## Superpowers
Useful design lessons include automatic behavior routing, systematic debugging, verification gates, durable execution ledgers, isolated workspaces, task review, and treating behavioral instructions as testable software.

[Superpowers](https://github.com/obra/superpowers) is available under the [MIT License](https://github.com/obra/superpowers/blob/main/LICENSE).

YallaFlow's distinct focus is persistent project-level engineering context, a work registry spanning multiple work types, project/work/execution state, pinned behavior contracts, and deliberate promotion of completed work into durable project knowledge. YallaFlow's skill metadata and instruction prose are original to this project; conceptual influence does not imply copied implementation text.
