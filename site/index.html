Why YallaFlow

The context your agent is missing

You describe the intent. YallaFlow keeps the durable state around the agent; the agent does the reasoning and the coding.

Persistent project memory

A reviewed understanding of your codebase, backed by evidence and flagged when that evidence changes.

Adaptive workflows

Bugs, features and investigations each get a lifecycle sized to the work. Small stays light.

Verified delivery

Nothing is done without fresh verification evidence, checked against what was asked.

Agent continuity

Every new session and every teammate starts from the approved understanding and recorded progress.

How it works

From request to remembered result

Day to day you talk to your agent. YallaFlow calls no AI model itself and sends no telemetry.

  1. Initialize

    yallaflow init connects Claude Code and Codex. Existing instruction files are kept.

  2. Describe the work

    Ask your agent in plain words. No need to say “use YallaFlow”.

  3. Approve once existing projects

    The agent maps the codebase without changing code, shows what it found and missed, and waits for your Approve.

  4. Route and build

    The request gets the right workflow, from a quick fix to a reviewed plan.

  5. Verify and remember

    Fresh evidence first. What was learned becomes reviewed project knowledge.

After the one-time approval, your original request continues automatically. Read the end-to-end guide.

Capabilities

What YallaFlow covers

Core capabilities are always on. Items marked Optional run only when you ask.

  • Claude Code and Codex

    First-party setup through each agent's instruction file.

  • Project onboarding

    A human-approved baseline that records coverage and limits honestly.

  • Knowledge persistence

    Facts, rules and decisions as files in your repository. Project memory

  • Workflow tracking

    Resumable lifecycles for bugs, features, changes and more. Workflows

  • Verification and evidence

    An append-only ledger of the checks that actually ran.

  • Shared Projects

    One understanding for the team, through ordinary Git. Shared Projects

  • Connected requirements Optional

    Import a GitHub, Jira or Azure DevOps ticket as a preserved source.

  • AI QC with Playwright Optional

    Browser checks planned from acceptance criteria; passed only if actually run.

  • Smart Demo Optional

    You approve the scenarios before anything is recorded. Not test evidence. Tickets, QC and demos

Quick start

Get started with YallaFlow

Works on a new or an existing repository. Requires Node.js ≥ 20.16.0.

TerminalInstall and initialize once

$ npm install -g yallaflow
$ cd your-project
$ yallaflow init

PromptThen ask Claude Code or Codex

  • Fix invoice totals.
  • Build an anonymous employee survey platform.

These are messages to your agent, not terminal commands.

Commands you might run yourself

$ yallaflow brief    # what YallaFlow knows and what's in progress
$ yallaflow status   # workflow state
$ yallaflow doctor   # integrity check
