New in 1.5.2

Connect your project. Choose its agent. Press Start.

The first hour is shorter. One Project page holds Overview, Run and Settings, and every step names what comes next.

  1. 1

    Connect an existing project

    Choose the folder in a picker that works like a file dialog. Before you confirm, you see exactly what yallaflow init would change. Uncommitted work is never touched.

  2. 2

    Choose the project's agent

    Codex, or Claude Code as experimental. The console can install Codex, sign you in and test the connection, one approved step at a time.

  3. 3

    Approve once, then ▶ Start

    The agent proposes the services. One card shows every exact command, and one approval starts the app. A command that changes later asks you again.

  • Nothing runs on its own
  • Shared stacks are never stopped by mistake
  • No secret values in plans or logs

Why YallaFlow

The context your agent is missing

You describe the intent. YallaFlow keeps the durable state around the agent; the agent does the reasoning and the coding.

Persistent project memory

A reviewed understanding of your codebase, backed by evidence and flagged when that evidence changes.

Adaptive workflows

Bugs, features and investigations each get a lifecycle sized to the work. Small stays light.

Verified delivery

Nothing is done without fresh verification evidence, checked against what was asked.

Agent continuity

Every new session and every teammate starts from the approved understanding and recorded progress.

How it works

From request to remembered result

Day to day you talk to your agent. YallaFlow calls no AI model itself and sends no telemetry.

  1. Initialize

    yallaflow init connects Claude Code and Codex. Existing instruction files are kept.

  2. Describe the work

    Ask your agent in plain words. No need to say “use YallaFlow”.

  3. Approve once existing projects

    The agent maps the codebase without changing code, shows what it found and missed, and waits for your Approve.

  4. Route and build

    The request gets the right workflow, from a quick fix to a reviewed plan.

  5. Verify and remember

    Fresh evidence first. What was learned becomes reviewed project knowledge.

After the one-time approval, your original request continues automatically. Read the end-to-end guide.

Install and upgrade

Get started in three steps

Works on a new or an existing repository. Requires Node.js ≥ 20.16.0. Install it as a tool, never as a dependency of your app.

  1. npm install -g yallaflow
  2. yallaflow init
  3. describe the work
  4. yallaflow console

TerminalInstall once, connect each project

$ npm install -g yallaflow
$ cd your-project
$ yallaflow init
$ yallaflow console      # optional: open it in your browser

Starting fresh? Use All projects → New project in the console instead of init.

PromptThen ask Claude Code or Codex

  • Fix invoice totals.
  • Build an anonymous employee survey platform.

These are messages to your agent, not terminal commands.

UpgradeWhen a new version is out, you decide when to upgrade

  1. npm install -g yallaflow@latest
  2. yallaflow upgrade status
  3. yallaflow agent refresh
  4. yallaflow doctor
  5. restart the console
$ npm install -g yallaflow@latest   # or an exact version: yallaflow@1.5.2
$ yallaflow upgrade status          # read-only: what, if anything, needs attention
$ yallaflow agent refresh           # only if the agent contract is reported outdated
$ yallaflow doctor

YallaFlow never updates itself. Your work items, project memory and sources are kept as they are. Restart yallaflow console so the browser loads the new version. Updating in detail
