# Code Review

## Purpose

Evaluate completed work independently of implementation activity.

## Review Areas

- compliance with the approved requirement or specification
- consistency with project architecture and conventions
- regressions and missing edge cases
- maintainability and unnecessary design weight
- security-sensitive behavior and data handling
- unintended scope or unrelated changes

Report findings with concrete evidence and severity appropriate to their impact. Distinguish blocking correctness issues from optional improvements.

## Guard

This skill describes review behavior only. It does not dispatch another agent, modify code, or replace verification.

## Result

Produce an evidence-backed review outcome with actionable findings or an explicit statement that no blocking issue was found.
