### CTX-0037 — Versioning and compatibility:

### CTX-0039 — Release process:
- Internal prereleases X.Y.Z-internal.N are each a single commit with an annotated tag v<version>.
- Before a release: syntax check, full suite, npm pack --dry-run, secrets scan, git diff --check and git status.
- CHANGELOG.md and per-version docs/upgrading-to-*.md are updated with each release.
- package.json files ships src, resources, docs, README.md, CHANGELOG.md and LICENSE.
